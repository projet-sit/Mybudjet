# Tests hors ligne – MyBudget

## À faire sur un vrai téléphone

1. Mode avion (compte déjà connecté) : créer un portefeuille, noter 5 dépenses, vérifier le Reste, fermer et rouvrir l'app.
2. Remettre internet : tout se synchronise, sans doublon.
3. Réseau très lent : aucun écran figé.
4. Deuxième téléphone sur le même compte : les données apparaissent.
5. Coupure en plein enregistrement : aucune opération perdue ni dupliquée.
6. Test sur un téléphone d'entrée de gamme (Tecno/Infinix) en Android 13+.
7. Détection par notifications en mode avion : l'opération est enregistrée, puis synchronisée au retour d'internet.

- [ ] Solde et Reste corrects hors ligne
- [ ] Aucun bouton muet
- [ ] Aucun message technique visible
- [ ] Synchronisation après retour réseau
