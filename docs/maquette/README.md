# Maquette MyBudget — archives de référence

Design de référence de l'onboarding (3 écrans) et maquette HTML d'origine.
Ces fichiers **ne sont pas** utilisables dans l'application tels quels :
ce sont des captures d'écran intégrales (design + textes + boutons),
pas des illustrations isolées. Les illustrations sont dessinées en CustomPaint
dans `lib/features/onboarding/onboarding_screen.dart`.

- `onboarding-1-depenses.png` — page 1 « Notez vos dépenses en quelques secondes »
- `onboarding-2-budgets.png` — page 2 « Gardez le contrôle de votre budget »
- `onboarding-3-hors-ligne-securite.png` — page 3 « Disponible même sans internet »
- `onboarding-maquettes.zip` — archive d'origine des 3 captures
- `files.zip` — assets brand d'origine (icon-ciel / logo-ciel, doublons des `assets/icon/` en place)
- `maquette-finances-personnelles.html` — export HTML de la maquette d'écrans
